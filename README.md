# FastAPI Starter

A production-ready FastAPI starter template built with clean architecture and best practices.

## Features

- FastAPI
- Clean Project Structure
- REST API Ready
- Environment Configuration
- Easy to Extend

## Project Structure

```
fastapi-starter/
│
├── app/
│   └── main.py
│
├── requirements.txt
├── README.md
├── .gitignore
└── LICENSE
```

## Installation

```bash
git clone https://github.com/your-username/fastapi-starter.git
cd fastapi-starter
pip install -r requirements.txt
uvicorn app.main:app --reload
```
